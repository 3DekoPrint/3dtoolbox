3 parts, farblich unterschieden: Name (bottom layer), Outline step 1, Outline step 2 (top, widest layer, carries the loop). Each step grows evenly around the name — with enough distance, neighboring letters merge automatically into one connected piece, so no single letter is left hanging loose. For 3D printing, a filament change between the layers is recommended (e.g. multi-material printer, or pause by hand).

3 layers as separate objects in one 3MF file — each can be colored individually in the slicer.
